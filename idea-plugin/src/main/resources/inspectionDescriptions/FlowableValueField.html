Reports a value("field", …) or originalValue("field", …) on a data-object query or builder whose field is not an input parameter of the operation named by operation("…") in the same fluent chain.

Example: createDataObjectInstanceQuery().definitionKey("DEMO-D010").operation("findAll").value("x", "") is reported as 'x' is not an input value of operation 'findAll' on data object 'DEMO-D010' (expected one of: id, label).

Quick fix: Replace with '…', the closest valid input value.

Checked only when the data object, its backing .service model and the operation all resolve from the index — an unknown data object or operation is a different finding, and a cold index is no verdict.
