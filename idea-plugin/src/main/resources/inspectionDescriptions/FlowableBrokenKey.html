Reports a string literal — or a constant reference — used as a Flowable model key at a catalogued API call site (startProcessInstanceByKey(…), caseDefinitionKey(…), formKey(…), …) whose value is not an indexed key of the type that position expects.

Example: runtimeService.startProcessInstanceByKey("DEMO-P999") is reported as 'DEMO-P999' is not a known Process key — did you mean 'DEMO-P001'?

Quick fixes: Replace with '…' on a literal; Change constant value to '…' on a constant whose initializer is a literal — that edit lands in the constants class, and the preview says so.

Silent when the project has no indexed key of that type, or the model index has not been built yet (the Atlas Hub shows its status; Rebuild Model Index forces one). The index reads deployment artifacts, .bar / .zip archives and — when enabled — the Flowable Design workspace. Recognize model keys anywhere in code does not widen this inspection: it checks call sites only.
