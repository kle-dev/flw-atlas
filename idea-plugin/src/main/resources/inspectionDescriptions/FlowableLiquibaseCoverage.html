Reports a <column name="…"> under createTable or addColumn, or a renameColumn newColumnName, that no columnMappings entry of the backing database .service model covers. Names are compared loosely, so CREW_ID_ matches crewId.

Example: Column 'LEGACY_NOTE_' is not mapped in Flowable service model 'DEMO-S010' — the table will have a column no model reads or writes.

No quick fix: the fix is in the model or in the changelog, and Atlas cannot decide which.

The changelog is matched to a service through its serviceDefinitionReferences property, the service's referencedLiquibaseModelKey, or a tableName match; when nothing matches the inspection stays silent. A column renamed or dropped later in the same file is honoured; an <include> of another file is not replayed.
