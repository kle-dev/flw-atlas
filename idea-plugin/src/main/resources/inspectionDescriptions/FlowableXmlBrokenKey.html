Reports a cross-reference in BPMN, CMMN or DMN model XML whose key matches no indexed model of the expected type: the attributes calledElement, processRef, caseRef, decisionRef, decisionTableReferenceKey, decisionServiceReferenceKey, caseDefinitionKey and formKey, and the extension elements eventType, triggerEventType, channelKey, processSequence, caseSequence, sla-definition-key and security-policy-model.

Example: <callActivity calledElement="shipping-prcoess"/> is reported with the suggestion did you mean 'shipping-process'?

Quick fix: Replace with '…' — on the attribute value and on the element text alike.

Values containing ${ or #{ are expressions and are skipped. Silent when the project has no indexed key of that type or the model index has not been built yet.
