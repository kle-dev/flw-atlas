Opens the page of the model a key literal names in the Atlas Explorer, inside the IDE — the relationship view: who references the model, what it uses, its findings and its diagram.

Available on a key at a Flowable API call site (a literal or a constant), and on any literal whose value is a known key when Recognize model keys anywhere in code is enabled. Ctrl/⌘-click on the same key opens the model file; this opens what the file means.
